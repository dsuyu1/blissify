# Save the Wedding: 45–50 minute workshop

Target 45 minutes: 5-minute introduction, 35-minute gameplay, and 5-minute debrief/exit. For 50 minutes, extend gameplay by five minutes and begin debrief at minute 45.

| Time | Activity |
| --- | --- |
| 0–5 | Introduction and Elena’s welcome (7) |
| 5–10 | Open the four role folders and sign in with the team ID cards |
| 10–22 | Concurrent vendor verification, privacy review, and budget/guest investigation |
| 22–32 | One useful AI prompt, source checking, and one reviewed revision |
| 32–40 | Joint Finance approval, then follow Mr. Planner’s alert and report Ever After |
| 40–45 | Debrief and exit |

Required recordings: 7, 3, 8, 4, 6. Optional recordings: 1, 2, 5, available in the collapsed extra messages section. Callback 4 appears after the trusted-contact check.

Put one room-specific team ID card in each role folder. Distribute one scenario prop in each folder: trusted vendor directory for Coordination, handling policy for Privacy, anonymous guest brief for Planning, and signed venue agreement for Finance. Keep the final approval slip with the facilitator until independent review. Document preparation must not wait on payment verification. Rotate the laptop operator. Give targeted hints after about two minutes without progress. Use recovery feedback without time penalties.

Keep the introduction and debrief protected. If extending to 50 minutes, gameplay ends at minute 45 and debrief runs 45–50.

## Shared room countdown

The first successful station sign-in starts a 50-minute countdown for the room. Printing cards or opening sign-in does not start it; rejoining does not reset it. Use a fresh room ID to start a new run. The final Ever After report stops the clock. If time expires, the team can still finish for practice. Incorrect answers do not deduct time.
