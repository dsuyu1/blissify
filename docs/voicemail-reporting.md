# Voicemail reporting practice

Select a caller to expand playback and message text. Open More options > Report suspicious message. Select a concern, optionally add details, then send. Reports are browser-local rehearsal records included in the exported room report. Participants can revise a report. Routine or verified messages receive different educational feedback from suspicious requests. Reporting neither verifies the caller nor blocks payments. Use independent verification before consequential actions.

This layout practices familiar voicemail list and contextual-menu patterns; it is not a literal Teams or iPhone UI. Actual menu names, features, and locations vary. Use your organization’s security reporting channel when an application lacks a Report option.

Validation: JavaScript syntax; isolated report-flow checks covering required reason, persistence, reopen/edit, benign-message feedback, mismatched-reason feedback, and cancellation. Visual browser QA was not performed for this update.
