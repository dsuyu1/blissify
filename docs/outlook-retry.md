# Stop the email that keeps coming back

Use a dedicated fictional workshop mailbox. Manually seed it with the messages below. The only required message is the delivery receipt; the other messages give the inbox a realistic background. Use an authorized test sender, and keep the fictional recipients in the message text only. The QR in the puzzle opens Outlook on the web and does not carry credentials.

In a shared room, Coordination opens the task from Planner. Admin rehearsal includes a sample receipt so you can run the puzzle without Outlook. None of the actions in the game send email. There is no new dependency on the existing wedding puzzles.
