# VowPilot phone puzzle

In a connected workshop room, sign in to the Privacy station, open the Planner, and select **Audit VowPilot’s permissions**. Generate a QR code and scan it with a phone. The phone doesn’t need a station login. QR invitations expire after 15 minutes; refresh the code if needed.

Players inspect the activity of a fictional wedding assistant, identify the action that created an unapproved public link, then replay the assignment with narrower permissions. The exercise never contacts an AI provider or performs a real send or share. The correct replay adds one task to the shared score. Existing prerequisites and the Ever After finale are unchanged; local rehearsal has no phone task.

Invitations are signed with the existing workshop secret and can only open this exercise in their room. They never contain station credentials. The mobile browser check is a game mechanic; device identification is not a security boundary. Ordinary room updates cannot submit the phone result.
